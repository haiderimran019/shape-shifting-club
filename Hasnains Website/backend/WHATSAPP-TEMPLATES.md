# WhatsApp message templates for Hasnain

Customers who order on the website send Hasnain a message that is **already filled in**:
order number, plans, total, name, number, gym or home, main goal and payment method.
So Hasnain doesn't need to ask for those details again.

Set these up once in the **WhatsApp Business app**:
**Settings → Business tools**, then *Greeting message*, *Away message* and *Quick replies*.
To use a quick reply, type `/` plus its shortcut in any chat, for example `/paid`.
